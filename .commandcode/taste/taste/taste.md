# Taste
- Wants apps built to be energy/battery efficient as an explicit design goal, not an afterthought. Confidence: 0.65
- Prefers polished, vivid UIs with rich data visualization (charts, at-a-glance stats) and real visual assets such as app icons/logos, over plain/functional screens; treats visual polish as a priority even after functionality works. Confidence: 0.7
- Values apps that surface actionable insight (tracking progress, goals, trends) rather than raw data alone. Confidence: 0.55
- Wants the agent to audit completed work against the original plan/checklist and report honestly what is done, partial, or missing (including gaps the agent itself wasn't asked about) rather than assuming tasks are complete. Confidence: 0.6
- When asked to review or improve an app's UI, expects the agent to look at the real running app visually (launch it on a device/emulator and capture screenshots of each screen) rather than judging from source code alone. Confidence: 0.7
- Expects the agent to go beyond observing and actually decide/prioritize what should change, delivering concrete, actionable UI change recommendations. Confidence: 0.5
